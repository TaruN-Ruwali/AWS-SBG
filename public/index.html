Why We Started

The AWS Student Builder Group (formerly AWS Cloud Club) at Graphic Era Hill University was formed to create an official, structured cloud and AI-focused student community aligned with the global AWS ecosystem.

  • ✓ Provide hands-on cloud learning beyond classroom theory
  • ✓ Foster a peer-driven learning environment
  • ✓ Enable students to work on real-world cloud projects
  • ✓ Build a strong bridge between students, faculty, and industry
